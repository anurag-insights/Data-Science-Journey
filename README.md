# Data-Science-Journey
My 30-Day Data Science Journey — documenting my daily learning, Python practice, data analysis, statistics, data visualization, and machine learning progress through hands-on projects using Jupyter Notebook.



30-Day Data Science Journey — 4 Weekly Parts.

Week 1: Python for Data Science
Days 1–7
Goal: Build a foundation for working with data using Python.
- Python revision: variables, data types, lists, dictionaries, loops, and functions.
- Learn NumPy arrays and basic calculations.
- Learn pandas Series and DataFrames.
- Load, inspect, filter, and clean datasets.
- Handle missing values and duplicate records.



Week 2: SQL, Statistics & Probability
Days 8–14
Goal: Learn to retrieve data and understand its statistical meaning.
- Practice SQL queries using PostgreSQL.
- Learn filtering, sorting, aggregation, and joins.
- Understand mean, median, mode, variance, and standard deviation.
- Learn basic probability and common statistical concepts.
- Practice interpreting results from real datasets.



Week 3: Exploratory Data Analysis & Machine Learning Basics
Days 15–21
Goal: Discover patterns in data and understand how machine learning works.
- Perform exploratory data analysis (EDA).
- Create charts using Matplotlib and Seaborn.
- Identify trends, outliers, and relationships between variables.
- Understand supervised vs. unsupervised learning.
- Learn features, target variables, training data, and testing data.
- Explore basic machine learning with scikit-learn.



Week 4: Machine Learning Project & Portfolio
Days 22–30
Goal: Apply your skills to a complete beginner-level Data Science project.
- Train a basic classification model.
- Evaluate model performance using suitable metrics.
- Understand clustering and its applications.
- Complete a small end-to-end Data Science project.
- Write a clear README and organize your GitHub repository.
- Review your learning and prepare for internship applications.
